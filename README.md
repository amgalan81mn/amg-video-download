# Amg-Video-Download — Chrome extension

Вэб дээрх видео, аудиог **MP4 (эх формат)** эсвэл **MP3** хэлбэрээр татна.

## Суулгах (2 минут)
1. `Amg-Video-Download.zip`-ийг (эсвэл GitHub-аас татсан zip-ийг) задлаад `amg-video-download` хавтсыг хадгална (устгаж болохгүй, Chrome тэндээс уншина).
2. Chrome-ийн хаягийн мөрөнд `chrome://extensions` гэж бичнэ.
3. Баруун дээд буланд **Developer mode**-ыг асаана.
4. **Load unpacked** дараад `amg-video-download` хавтсыг сонгоно.
5. Пазл (🧩) дүрс дээр дараад Amg-Video-Download-ыг 📌 тогтооно.

## Хэрэглэх
- **Баруун товч** → *Amg-Video-Download*:
  - *Энэ видео/аудиог татах (MP4)*: шууд файлтай видео дээр ажиллана.
  - *MP3 болгож татах*: аудиог нь салгаж MP3 болгоно.
  - *Энэ линкнээс медиа хайж татах*: линк дээр баруун товч дарна.
  - *Энэ хуудсан дээрх бүх медиаг харах / сонгох*: олдсон бүх медиаг жагсааж, сонгуулна.
- **Дүрс дээр дарах** → тухайн хуудсан дээрх медиагийн жагсаалт гарна. Олныг нь чагтлаад, MP4 эсвэл MP3-ыг сонгоод татна.
- **Линкээр**: дээд талын талбарт линк буулгаж *Хайх* дарна.
- **Хадгалах хавтас**: popup-ын доод талын ⚙ хэсэгт `Downloads` доторх хавтасны нэрийг бичнэ (жишээ нь `Videos/Facebook`). Хавтасны нэрийг санаж үлдэнэ, анхны утга нь `Amg-Video-Download`.
  - *Хадгалах бүрт байршил асуух*-ыг асаавал Chrome-ийн "Save As" цонх гарна. Энэ цонхоор `Downloads`-аас гадуурх дурын хавтсыг сонгож болох ба сүүлд сонгосон хавтсыг Chrome санана.
- **Нэр давхцах үед** цонх гарч *Шинэ нэрээр хадгалах*, *Дарж бичих*, *Цуцлах* гэсэн сонголт өгнө.
- **Хадгалсны дараа** видео дүрстэй "Хадгаллаа ✓" мэдэгдэл гарна. Түүн дээр дарвал файл байгаа хавтас нээгдэнэ, *Нээх* товч дарвал файл тоглоно.

## Зөвлөмж
- Facebook, Instagram зэрэгт эхлээд **видеог хэдэн секунд тоглуулаад** дараа нь ⟳ дарвал илүү олон холбоос олдоно.
- **Нэг видео = нэг мөр.** Facebook нэг видеог олон чанараар (360p … 1440p) дамжуулдаг. Эдгээрийг нэг мөрөнд нэгтгэж, хамгийн сайныг нь **★ Шилдэг** гэж харуулна (дуутай хувилбарыг түрүүлж сонгоно). Бусад чанар нь *Бусад чанар (N)* дотор 🎬 дүрс, чанар, хэмжээтэйгээ харагдана.
- 🔇 *дуугүй* гэсэн хувилбар нь зөвхөн дүрс байдаг (Facebook дүрс, дууг тусад нь дамжуулдаг). Дуу хэрэгтэй бол 🔊 *дуутай* хувилбарыг, эсвэл 🎵 *Зөвхөн дуу*-г сонгоно.
- Мөр бүрийн зүүн талд видеоны **жижиг зураг**, үргэлжлэх хугацаа харагдана. Хулгана аваачихад дуугүй тоглож, аль видео болохыг ялгахад тусална.
- **Файлын нэр**: Facebook-ийн видеог `amg-video-download-<видео ID>.mp4` гэж хадгална (жишээ нь `facebook.com/reel/1159181930234923` → `amg-video-download-1159181930234923.mp4`). Шилдэгээс бусад чанар нь `…-1440p.mp4` гэх мэт төгсгөлтэй.
- Одоо нээлттэй байгаа reel хамгийн дээр гарч, автоматаар сонгогдоно. Доорх бусад мөр нь Facebook урьдчилан ачаалсан дараагийн reel-үүд байдаг.
- HLS (m3u8) урсгалыг `.ts` эсвэл `.mp4` болгож нэгтгэнэ. Шифрлэгдсэн (DRM) урсгал татагдахгүй.

## Хязгаарлалт
- Chrome extension зөвхөн `Downloads` доторх хавтас руу шууд хадгалж чадна. Өөр диск эсвэл хавтас руу хадгалах бол "Хадгалах бүрт байршил асуух"-ыг асаана уу.
- Нэр давхцлыг Chrome-оор татсан, одоо ч байгаа файлуудаас л шалгана.
- **YouTube**: YouTube видеог хамгаалагдсан, хэсэгчилсэн урсгалаар дамжуулдаг тул ихэнхдээ татагдахгүй. Netflix, Spotify зэрэг DRM-тэй контент огт татагдахгүй.
- MP3 хөрвүүлэлт браузер дотор хийгддэг тул маш урт (1 цагаас дээш) видеонд санах ой их шаардана.
- Зөвхөн өөрийн контент, эсвэл татахыг зөвшөөрсөн видеог татаарай. Сайтуудын үйлчилгээний нөхцөл, зохиогчийн эрхийг хүндэтгэнэ үү.
